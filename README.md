# DataForge
DataForge é uma ferramenta client-side desenvolvida para traduzir planilhas de gestão de risco em interfaces visuais modernas para tomada de decisão executiva. Ao consumir matrizes padronizadas em Excel (.xlsx), a aplicação gera automaticamente dashboards gráficos dinâmicos sem a necessidade de softwares adicionais ou infraestrutura de backend.
